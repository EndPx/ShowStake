# ShowStake event factory: review candidate

Local candidate only. Not deployed or technically accepted. This factory creates a keyless child and initializes the pinned ShowStake native-USDC leaf; it does not publish an event, configure a cap, unpause a child, or transfer fungible tokens. On Rhea mainnet the child initializes paused with zero cap. The organizer must configure and publish directly on the child in separately authorized calls.

`new(canonical_ft, network, policy_version, provider_account, provider_kind)` pins `showstake-native-usdc-rhea-linked-withdraw-review/2` on mainnet and `showstake-native-usdc-event/1` on testnet, with immutable provider identity. Mainnet accepts only Circle native USDC `17208628f84f5d6ad33f0da3bbbeb27ffcb398eac501a31bd6ad2011e36133a1`, `contract.main.burrow.near`, and `RHEA_MAINNET`; testnet requires `.testnet` accounts and `MOCK_TESTNET`. The factory's own deployment identity is a separate trust decision. An owner with FullAccess to its account can change factory code or create direct subaccounts; generated children contain no keys and cannot be upgraded by a child key. Do not assume an arbitrary external account can squat on a direct factory child.

`provision(request_nonce, code)` takes base64 JSON bytes, exact 235060-byte length, and SHA-256 `49a591ba26a4a23d05c01cc343779f1c66aa5da0384e3a663a37f4e5edb59b70`. Organizer is always the predecessor. First call must attach exactly `quote_provision(organizer).total` yoctoNEAR. A completed replay must attach zero; other deposits cause the whole call to revert. `get_child_id`, `get_request`, `get_child`, `list_children`, `get_native_accounting` and `get_config` expose registry, policy and funding information. Nonce replay cannot create a second child.

A failed child batch makes the child funding claimable, without claiming it was paid. The original organizer calls `claim_failed_funding(request_nonce)`; the private receipt callback marks Paid only on success. A failed transfer becomes claimable again. An in-flight or lost callback requires reconciliation design before any retry: the factory never blindly resends an unresolved transfer. A recovery probe with failed or mismatched `get_config` leaves the request Pending; it cannot prove the child batch failed and does not authorize a refund.

DTO example for factory initialization (testnet): `{"canonical_ft":"mockusdc.testnet","network":"testnet","policy_version":"showstake-native-usdc-event/1","provider_account":"provider.testnet","provider_kind":"MOCK_TESTNET"}`. Provision: `{"request_nonce":1,"code":"<base64 exact pinned wasm>"}`. Its `quote_provision` response uses `child_funding`, `registry_fee`, `total`, `attached_gas_tgas`, `pending_timeout_blocks`. `get_request` retains `organizer`, `request_nonce`, `child_id`, `state`, `child_funding`, `registry_fee`, `attached`, `excess_refunded` and adds `refund_state`, `refund_attempt`.

Unit tests are local and do not prove NEAR Sandbox atomic rollback, gas sufficiency for caller-provided code, child storage requirement, transaction or payment completion. Quote and exact funding rely on storage assumptions that require Sandbox receipt-level measurement for this new leaf. Storage byte price and registry growth are evaluated at call time; if the quote drifts, the exact-deposit call reverts and should be requoted. No mainnet readiness, payout or live Rhea proof follows from these tests.

## Global discovery candidate (schema 2)

`get_config` reports factory policy `showstake-factory-d039-global-ready/2` and schema version 2. This is a fresh factory layout with no migration. `list_all_children(from_index, limit)` accepts limits 1 through 20 and returns `ChildView` records across organizers in Ready callback completion order. Pending and Failed requests are excluded. The organizer-specific listing retains its existing provisioning-order semantics. `request_nonce` remains a JSON number and new requests reject values greater than 9007199254740991 before mutation.

Each provision quote includes a prepaid reserve for one global Vector entry, including if the request fails. The immediate registry growth is measured; the future entry reserve is calculated from its serialized size and trie overhead. The Vector length is part of fixed-size root state. This changed quote and eventual callback growth require fresh Sandbox measurement; the historical result below does not validate them. The v3 linked-withdraw leaf pin adds eight bytes to the RHEA_MAINNET initialization funding estimate for its retry_after_block field; the mock testnet estimate has no such addition. This factory and leaf combination requires fresh Sandbox measurement and is not authorized for funded actions.
