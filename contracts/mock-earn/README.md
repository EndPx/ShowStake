# Testnet Mock Earn

TESTNET ONLY zero-yield custody fixture. Scaffold generated by official cargo-near 0.23.0; near-sdk pinned to 5.30.1. Not Rhea, not evidence of live yield or mainnet liquidity.

new(token, controller) requires .testnet accounts. Canonical FT ft_transfer_call with empty msg records a position owned by sender. get_position(account_id) includes available and in-flight principal. withdraw(amount) transfers only to caller; returned promise resolves after private callback finalizes or restores position. set_failures(reject_supply,reject_withdraw) is controller-only test control.

No borrowing, APY, fabricated yield, or redirectable beneficiary.

Build: cargo test --lib --offline; cargo build --target wasm32-unknown-unknown --release --offline. Reuse existing target cache.

Evidence must be labelled TESTNET_MOCK_EARN and cannot pass Rhea technical acceptance.
